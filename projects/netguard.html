Story

Network and device security is an area of sustained personal interest — a large share of real-world security incidents originate at the point of network connection, not from files already resting on disk. NetGuard was built to observe traffic at exactly that layer: what a device sends and receives the moment it connects, rather than scanning what's already stored.

Validation was the hardest part of the build: proving that packet parsing and detection logic held up against real, messy traffic rather than a handful of clean test cases. The project grew from a terminal-based analysis script into a full application: a live 5-panel dashboard, an IP reputation system with automatic threat-scoring, and a custom rules engine that lets a user reload new detection logic at runtime without restarting capture.

Planned extensions include reimplementing core components in C/C++ for lower-level performance, and expanding automated classification of known-malicious network behavior.

Technical Highlights
  • 01Raw-socket packet engine. Engineered a real-time network intrusion detection system (~2,900 LOC, 13 modules) that captures and parses raw traffic from Ethernet through HTTP via AF_PACKET raw sockets, manually decoding headers with struct — no packet-parsing libraries used.
  • 02Port-scan & flood detection. Implemented 4 port-scan detection algorithms (SYN, FIN, XMAS, TCP Connect) and a rate-based SYN-flood detector using sliding time windows and TCP handshake state tracking, with alert hysteresis to prevent duplicate-alert flooding.
  • 03Self-calibrating baseline. Replaced fixed alert thresholds with a baseline that learns each network's normal behavior over a 5-minute window, scaling alert severity by standard deviation rather than a hardcoded cutoff.
  • 04IP reputation system. Built blacklist/whitelist support and suspicion scoring that automatically promotes repeat offenders to "malicious," persisted as JSON state across runs.
  • 05Hot-reloadable rules engine. Designed a custom YAML rules engine supporting compound conditions and windowed thresholds, reloadable at runtime without restarting capture.
  • 06Multi-threaded live dashboard. Built a real-time terminal dashboard (5 live panels: stats, alerts, connections, top talkers, packet feed) with concurrent capture/render threads coordinated via thread-safe queues, plus a hand-written PCAP exporter for offline analysis in Wireshark.
