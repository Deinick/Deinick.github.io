Story

TelusGuardAI was built in 24 hours at a hackathon — the first hackathon, and one of the first substantial team projects, undertaken. The system analyzes TELUS network disruptions during events like storms or outages: a user asks a plain-language question, and a multi-agent backend pipeline gathers web and weather intelligence to return affected areas, severity, and confidence, visualized on an interactive coverage map. The central challenge on the front end wasn't technical execution so much as translation: turning an open-ended problem statement into a specific, buildable idea.

Of two front-end team members, UI design and development was owned in full, from initial concept through several iterations to a final enterprise-style dark interface; a teammate independently built the mapping component and the multi-agent backend. The most demanding technical work was integration: bringing two independently developed front-end pieces together with the backend into one coherent system.

Given more time, the map would be developed into a fuller application in its own right, rather than remaining the project's single centerpiece.

Technical Highlights
  • 01End-to-end UI layer. Built the dashboard's UI layer end to end: the tower Details Panel, a Safety Panel, an Event and Action Log, and a full dark-theme pass across the application.
  • 02Live AI integration. Wired live AI-driven impact classification output, produced by a teammate's multi-agent backend, into the map, KPI tiles, and action log in real time.
  • 03Dashboard architecture. Designed and implemented the core dashboard layout and component structure, from an initial concept through several iterations to a final enterprise-style dark UI.
