Story

FutureSpend was built at Mountain Madness 2026, a 24-hour hackathon held March 1 and sponsored in part by RBC. Rather than a single fixed theme, teams chose from several open tracks and competed within smaller, focused categories; the team's track was RBC-aligned financial tooling. The system connects a user's calendar to a spending forecast, predicting likely spend by category from upcoming events and surfacing insights, savings challenges, and an AI coach.

Extending this project further would mean building a native mobile application and revisiting the visual design for something more distinctive under less time pressure.

Technical Highlights
  • 01End-to-end backend pipeline. Owned the backend pipeline under a 24-hour deadline: calendar events flow through a feature-extraction layer into a rule-based prediction engine, chosen over ML for reliability with zero labelled training data.
  • 02API contract design. Designed and documented the API contract for the team, writing API.md with endpoint specs, request/response shapes, and examples so teammates could build the frontend independently.
  • 03Full-stack integration. Built the integration layer connecting the Next.js frontend to the backend via api.ts, wiring 5 pages from static mocks to live API calls, with a graceful mock-data fallback for reliability.
  • 04Automated test suite. Backed the pipeline with a 277-line automated test suite covering the full request flow, plus separate import and data-validation tests.
